# LaunchDarkly React Demo Client

This is the React frontend for the LaunchDarkly full-stack demo application, built with Vite.

## Requirements

- Node.js 22.x or higher
- npm 10.x or higher

## Available Scripts

### `npm start` or `npm run dev`

Runs the app in development mode using Vite.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page will reload when you make changes.\
You may also see any lint errors in the console.

### `npm run build`

Builds the app for production to the `dist` folder.\
It correctly bundles React in production mode and optimizes the build for the best performance.

### `npm run preview`

Serves the production build locally for testing.

## Features

- LaunchDarkly React SDK integration
- Real-time feature flag evaluation
- Server-sent events for live updates
- Modern Vite build tooling

## Environment Variables

- `VITE_LD_CLIENTSIDE_ID` - LaunchDarkly client-side ID
